# Lab Portal · Drug Disco Lab

Internal portal for lab members. The app list is encrypted — the page asks
for the lab access code before showing anything.

## Add / edit apps or change the access code
1. On the lab PC, open **portal-admin.html** (in the Lab Portal folder — it is
   *not* in this repository and must never be uploaded here).
2. Pick this repository's `index.html`, edit the apps, set the access code.
3. Click **Encrypt & download**, then upload the new `index.html` here
   (Add file → Upload files → Commit changes).
